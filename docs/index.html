Everything a scrape reads is one line.

A name, its labels in braces, a number and the instant it was read. The rest of this page is that line, arranged. The specimen below was written by the encoder in this repository — copied, not typed.

Two formats, one model. The compatibility format writes milliseconds and stops there. OpenMetrics writes seconds, a # UNIT line, exemplars and a closing # EOF. Both come out of the same collected families, so a switch between them cannot change a count.

The number above is cumulative on purpose. A histogram is not a bucket count but a budget: le="0.1" says how many samples took 100 milliseconds or less, so a reader never has to add steps to answer the question it came with.

What the labels say

le is the step's upper bound. Labels are sorted before they are written, so two scrapes of the same series diff cleanly.

+Inf is always the last step, and always equal to _count. This window has nothing above 2.5 s.

Three things this library will not decide for you.

When a scrape happens, what is allowed to take a name, and which format leaves the process. All three are handed in, which is why the same code serves a server, a replay of last night, and a test that needs the bytes to be the same twice.

The clock

A collection is stamped with the moment the caller says it happened. Nothing here reads a clock, so a window replayed from a fixture carries the fixture's time, and two runs of a test compare equal. 

let families = registry.collect(
  at=1_700_000_015.0,
)
// samples without a time of their own
// are stamped with it; a backfilled
// sample keeps the date it was given.

The names

A registry is the only place a name is spent. Register twice and the second attempt is refused with the name it would have collided with, rather than the two quietly merging into one series. 

registry.register(
  "jobs", "Jobs seen.", counter,
)
// Refused: "metric already
// registered: jobs"

The format

The encoder is chosen at the edge, from the request's own Accept. One collected snapshot can leave as the compatibility text or as OpenMetrics; the counts are the same object. 

@expo.negotiate(accept)
// Text004 · OpenMetrics100

@expo.text(families)
@expo.openmetrics(families)
// same counts, different edges
